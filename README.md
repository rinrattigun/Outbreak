# Outbreak — зомби-апокалипсис для SillyTavern

## Установка
Скопируй папку `Outbreak` в
`SillyTavern/data/default-user/extensions/` (или `public/scripts/extensions/third-party/`),
перезагрузи страницу SillyTavern. Нужна версия с `SillyTavern.getContext()` (1.12+).

## Где что
- **Волшебная палочка** → «Outbreak: панель» (показать/скрыть) и «Outbreak: выключить/включить».
- Кнопка **⏻** в шапке панели выключает расширение целиком: ничего не считается и в промпт ничего не добавляется.
- **Панель расширений → Outbreak**: формат времени, глубина вставки, свайп/кубики.
- В каждом чате расширение нужно один раз запустить кнопкой «Начать» — чаты без запуска не затрагиваются.

## Как работает
Состояние каждый раз пересчитывается из истории чата + ваших ручных действий + подтверждений,
поэтому свайпы, правки и удаления сообщений ничего не ломают. Хранится в метаданных чата.
Все числа баланса — в `engine.js` (объект `DIFF`).
